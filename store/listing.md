# Listing

## Title
GitHub Changes

## Summary
Makes reviewing PR and commit changes on GitHub easier.

## Description
GitHub Changes adds a small popup with helpers for reviewing code changes on GitHub.

Credits:

•  "compare" icon from https://www.iconsdb.com/black-icons/compare-icon.html (by icons8)

## Single purpose
Help developers view file changes on GitHub by folding, sorting, and marking changed files.

## Permission justification
- activeTab:
    - making trivial UI changes in the active tab
- scripting:
    - injecting content.js into the current page to fold, sort, and mark files
- tabs:
    - reading the active tab's URL to check whether it is a supported GitHub page
